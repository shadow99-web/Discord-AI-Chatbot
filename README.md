# Discord AI Chatbot 🤖

Your Discord AI companion.

## Features

- Hybrid command system
- Image generation
- Free LLM model support
- Mention recognition
- Reply-aware message handling
- Channel-specific activation
- Open-source model support
- Secure credential management via environment variables
- Optional web access

## Commands

- `/help` — show available commands

## Configuration

Set your language and personality preferences in the project configuration file.

## Usage

Provide your Discord bot token and API key in your environment configuration, then run the bot with the project startup command.
